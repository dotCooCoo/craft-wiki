VectorCraft draws with paths. Every shape, line and letter is an outline that stays sharp at any size. The guides below start with a new document and end with automation, and you can read each one on its own.

Shortcuts are written for Windows and Linux first, then macOS: Ctrl+G / Cmd+G. You can change every shortcut in **Edit › Keyboard Shortcuts…**. **Help › Search Commands…** (Ctrl+Shift+/ / Cmd+Shift+/) finds any menu command by name.
